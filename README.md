# Jamstack Handbook

Static Astro site for [jamstackhandbook.com](https://jamstackhandbook.com).

## Development

Requires Node.js 22.23.4 or later.

```sh
npm install
npm run dev
npm run build
npm run preview
```

The production build is written to `dist/` and can be served by any static host. No Astro server adapter is configured.
